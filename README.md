# Summit Grounds � Coffee & Books

A multi-page site for a Colorado mountain coffee shop with a tiny bookstore nook.

## Preview

Open the home page in your browser:

```bash
open index.html
```

Or double-click `index.html` in Finder.

## Pages

| File | What's on it |
|------|----------------|
| `index.html` | Home � hero + newsletter signup |
| `about.html` | Our Story |
| `menu.html` | Menu (coffee, tea, food tabs) |
| `books.html` | The book nook |
| `visit.html` | Hours, location, and visit info |

## Shared files

- `styles.css` � all colors and layout (shared by every page)
- `shared.js` � mobile nav + newsletter form
- `menu.js` � menu tab switching (menu page only)

## Sections

- Hero with animated mountain silhouette (home page)
- Family story with shop window illustration
- Tabbed menu (coffee, tea, food)
- Interactive book shelf
- Hours, location, and newsletter signup
